# 🤖 Phone Intelligence Telegram Bot

An AI-powered Telegram bot that provides phone number intelligence using APIs, OCR, and speech recognition.

## 🚀 Features

### 📱 Phone Number Lookup
- Detects phone number information using AbstractAPI
- Provides:
  - Country
  - Region
  - Carrier
  - Phone type
  - Validity
  - Timezone

### 💬 WhatsApp Link Generator
- Generates a direct WhatsApp chat link for any phone number.

### 📇 QR Code Generator
- Creates a contact QR code for easy saving.

### 🖼 Image Phone Number Extraction
- Upload an image or screenshot.
- Uses OCR to extract phone numbers.
- Provides actions:
  - Lookup details
  - Generate WhatsApp link
  - Generate QR code

### 🎙 Voice Phone Number Extraction
- Accepts voice messages.
- Converts speech to text using Whisper.
- Extracts phone numbers automatically.

### 🌐 Multi-language Support
- Users can select:
  - English
  - Urdu
